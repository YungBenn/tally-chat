Cost math

The formulas behind every number in the design doc.

Variables

S system prompt tokens · u user message tokens · a answer tokens · k turn number · N total turns

No caching (lesson 1)

input(k)        = S + (k − 1)·(u + a) + u
total_input(N)  = N·(S + u) + (u + a)·N·(N − 1)/2     ← quadratic in N
total_output(N) = N·a
cost            = (total_input·price_in + total_output·price_out) / 1,000,000
typed share     = N·u / total_input

Rules of thumb

  • Double the turns, roughly quadruple total input.
  • An answer token is paid once as output, then again as input on every later turn. Shorter answers save twice.
  • The system prompt is paid every turn, but it grows linearly; history grows quadratically and dominates long threads.
