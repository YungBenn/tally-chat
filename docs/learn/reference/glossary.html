Glossary

Every lesson uses these words exactly as defined here.

TermMeaningFrom
TokenThe unit a model reads and writes, and the unit you are billed in. A word, part of a word, a character or a byte. ~3.5 English chars on older Claude models; Claude 4.7+ tokenizer yields ~30% more tokens for the same text.L1
MTokOne million tokens. Prices are quoted per MTok.L1
Input tokensEvery token in the request: system prompt, full message history, new message.L1
Output tokensEvery token the model generates. Several times the input price (5x on Sonnet 5.5).L1
TurnOne user message plus the assistant reply to it. One API request.L1
System promptStanding instructions sent at the top of every request (system field). Paid on every turn.L1
StatelessThe API keeps no memory between requests. Your app resends the full history every turn.L1
Context windowEverything the model sees in one request: its working memory. Has a maximum size per model.L1
Usage blockThe usage object in every response reporting token counts for that request.L1
Conversation accumulationThe quadratic growth of total input tokens as history is resent each turn. Cost driver #1 in the design doc.L1
