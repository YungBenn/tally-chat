# Where holo goes

Holo is allowed only where this table says. Everything else uses plain hairlines.

| Component | Holo | Intensity | Motion |
| --- | --- | --- | --- |
| Composer | edge while focused | vivid | shimmer |
| Send button (primary) | edge when enabled | default | sweep on hover |
| Button: secondary, outline, ghost, danger | never | | |
| Thread item | edge when active; 14px dash when streaming | subtle | dash shimmers |
| Assistant message | 1.5px rail and caret while streaming | full | caret blinks |
| Cache status | ring and pill edge when warm | subtle | slow breathe, draining ring |
| Inspector layer row and context bar segment | edge when selected | default / vivid | none |
| Tabs | 2px underline on the selected tab | full | none |
| Progress bar, slider | fill under 80% | full | none |
| Line chart | the line | full | draws in once |
| Bar chart, table, legend | never (series colors) | | |
| Popover | edge only when content is live | subtle | none |
| Dialog | frame edge | subtle | none |
| Stat tile | one highlighted tile per page; `holo-text` on its value | default | pointer tilt |
| Provider card | edge while selected or editing | default | none |
| Sign-in card | edge; mark draws in | subtle | line draw once |
| Divider | `holo` variant once per page | 0.7 | none |
| Blockquote | 1px left rule | 0.85 | none |
| Logo | outline and ruler ticks | full | line draw on first load |
| Inputs, selects, checkboxes, switches, badges (except `live`), toasts, banners, errors, disabled anything | never | | |
