# ThreadItem

Row in the sidebar thread list.

- States: rest (`foreground-muted`), hover (`surface-hover`), active (`surface-active` + subtle holo edge), unread (bold title + amber dot), streaming (a 14px shimmering holo dash before the title).
- Right side shows the thread cost in mono, or the unread dot.
- Group threads under Today, Yesterday, Previous 7 days, Older.
