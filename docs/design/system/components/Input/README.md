# Input

Single-line text field with an optional label, help text and error.

- Rest: `surface-raised` with a `border-strong` outline (3:1). Focus swaps the border for a solid 2px `ring`. Error uses `danger` for border, ring and message, with an icon.
- Use `mono` for URLs, keys and money so they read literally.
- Labels are short nouns in sentence case. Help text says what happens, not what to type.
- Don't put holo on inputs; the composer is the only text field that gets a holo edge.
