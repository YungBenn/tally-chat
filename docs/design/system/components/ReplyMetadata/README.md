# ReplyMetadata

One mono line under each reply: model (effort) · cost · input (cached share) · output. Click opens the cost breakdown popover.

- Cached share is in `cached`. Separators are `·` in `foreground-subtle`.
- Breakdown rows use the layer swatches (solid cached, hatched write, outlined fresh), a total, and savings vs no cache.
- Format: `$0.0043` (4 decimals under $0.01), token counts as `12.4k`.
