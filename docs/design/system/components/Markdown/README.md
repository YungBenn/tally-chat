# Markdown

Rendering rules for reply content in `prose`.

- H2 19/28 600, H3 16/24 600, paragraphs 14px apart. Lists indent 22px with subtle markers; ordered markers in mono.
- Inline code: mono 0.875em on `surface-sunken` with a hairline. Links in `accent`, underlined at 40%.
- Blockquote: a 1px holo rule on the left (quoted source) in `foreground-muted`.
- Tables: header in `foreground-muted` over a `border-strong` rule; numeric columns right-aligned in mono.
