# ThreadView

The whole thread view: sidebar, a conversation with a checkpoint, branch switcher, code block and a streaming reply, the focused composer with its cost strip, and the inspector open. Shown in light and dark.

Holo in this view, and nowhere else: the active thread, the streaming thread dash, the streaming rail and caret, the focused composer, the send button, the warm cache pill, the selected inspector layer. Everything else is plain hairlines.

Responsive: under 1200px the inspector becomes a bottom sheet; under 900px the sidebar becomes a left sheet; at 360px the composer bar wraps the model and effort pickers into one menu.
