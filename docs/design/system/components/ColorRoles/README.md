# ColorRoles

How the color roles stack, shown on real surfaces in both themes.

- Set the page on `background`, panels on `surface`, lifted controls on `surface-raised`, wells on `surface-sunken`.
- Text is `foreground`, `foreground-muted` or `foreground-subtle`, never a raw neutral step.
- Domain colors are meanings, not decoration: `cached` (cheap), `to-be-written` (one-time write, always hatched), `fresh` (full price, always outlined). Cache temperature: `cache-warm`, `cache-cooling`, `cache-cold`. Budget: `budget-ok`, `budget-near`, `budget-paused`. Savings: `savings-positive` with a plus, `savings-negative` with a minus.
- Chart series use `chart-1` to `chart-6` in order, with labels.
