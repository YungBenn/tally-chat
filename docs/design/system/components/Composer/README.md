# Composer

Where the user writes. Multiline input, attach, model picker, effort, output mode, send or stop, and the cost strip under it.

- Rest: `surface-raised`, hairline, `shadow-raised`. Focused: the border becomes a vivid shimmering holo edge, the signature moment of the app.
- Send is a primary icon button with holo only when there is text. While streaming it becomes Stop (secondary, filled stop icon).
- Paused by budget: `surface-sunken`, controls disabled, the budget banner sits above it.
- Effort shows 1-4 rising bars; output mode is a small SegmentedControl.
