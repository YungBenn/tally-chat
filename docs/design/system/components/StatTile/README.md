# StatTile

A number with a label and a delta: spend, hit rate, keepalive cost, net savings.

- Value in `mono-hero`-like 28px tabular figures. Delta in mono with an arrow; color says good or bad and the sign says the direction.
- `highlight` adds a holo edge to the one tile that matters most; `tilt` makes its sheen follow the pointer slightly. `hero` uses `holo-text` on the value (one per page).
