# CodeBlock

Fenced code in replies: header with language and filename, copy button, line numbers, syntax theme from the `code-*` tokens.

- Body on `surface-sunken`, header on `surface-raised`, `radius-popover`, 13/20 mono with ligatures off.
- Copy swaps to a check and "Copied" for 1.6s (`aria-live`).
- Long lines scroll horizontally; never wrap code.
